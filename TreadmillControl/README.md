# Treadmill Control — Android-приложение для беговой дорожки UNixFit-990x

Приложение для управления беговой дорожкой по BLE через профиль **FTMS**,
с подключением нагрудного пульсометра и автоматической регулировкой скорости по пульсу.
Работает полностью офлайн (разрешение INTERNET не запрашивается).

## Возможности
- Подключение к дорожке по FTMS (0x1826) + резервный проприетарный протокол FitShow
- Подключение пульсометра (0x180D)
- Управление скоростью, старт/стоп, экстренная остановка
- Автоматическая регулировка скорости по целевому пульсу/зоне
- Тренировочные программы с интервалами + импорт/экспорт JSON
- Журнал тренировок (Room/SQLite)
- Экран Debug (лог BLE + отправка hex-команд)

## Сборка через GitHub Actions
1. Загрузите код в репозиторий (ветка `main`):
   ```bash
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<user>/TreadmillControl.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions** → дождитесь зелёной галочки **Build APK**.
3. Откройте завершённый run → блок **Artifacts** → скачайте `treadmill-debug-apk`.

## Локальная сборка
```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
Либо откройте папку в Android Studio Hedgehog+.

## Установка APK на телефон
1. Перекиньте `app-debug.apk` на телефон.
2. Разрешите установку из неизвестных источников.
3. Откройте файл и установите.
   Или через adb: `adb install app-debug.apk`.

## Использование
См. экран «О программе» внутри приложения.

## Отладка FitShow
Если стандартный Control Point (0x2AD9 / 0x2A66) не работает — откройте экран **Debug**,
посмотрите все сервисы/характеристики дорожки и при необходимости:
- в **Настройках** выберите протокол **FitShow** и укажите UUID вручную,
- отправляйте тестовые команды в hex через Debug-экран.

## Конфиденциальность
Разрешение `android.permission.INTERNET` отсутствует в манифесте. Всё хранится локально.
